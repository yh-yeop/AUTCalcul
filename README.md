# 어센틱심볼 최적 강화 계산기

메이플스토리 어센틱심볼(세르니움 ~ 카르시온, 그랜드: 탈라하트 · 기어드락) 보유 현황을 입력하면,
**N회 업그레이드를 최소 메소로 하는 지역/레벨 조합**, **예산 안에서 올릴 수 있는 최대 횟수**,
**전 지역을 목표 레벨까지 올리는 비용과 일퀘 기준 소요 일수**를 계산해 줍니다.

👉 https://yh-yeop.github.io/AUTCalcul/

## 기능
- 지역별 현재 레벨 + 보유 성장치(심볼 개수) 또는 만렙까지의 진행률(%) 입력 (100% = 만렙에 필요한 심볼 전부)
- 전체 지역의 "다음 1회 강화" 비용을 최소 힙으로 관리해 가장 싼 강화부터 N회 선택
  (지역별 비용은 레벨이 오를수록 증가하고 강화 1회의 효과는 지역에 관계없이 같으므로 탐욕 선택이 최적해)
- 예산 모드: 쓸 수 있는 메소(억)를 넣으면 그 안에서 가능한 최대 횟수, 남은 예산, 다음 강화까지 모자란 금액
- 목표 레벨 모드: 활성 지역 중 Lv.N 미만인 지역을 전부 N까지 올리는 비용·횟수. 성장치가 모자라 막힌 지역은 부족 개수와 일퀘 기준 일수를 표시
- 일퀘 타임라인: 매일 일퀘 심볼(세르니움 30개, 그 외 15개)이 들어온다고 보고 현재 목표를 달성하는 가장 빠른 날짜와 "k회째 강화가 가능해지는 날"을 표로 표시 (결과 아래 접이식, 최대 400일)
- 지역 선택 심볼 교환권: 개수 하나만 입력하면 아무 지역에나 쓸 수 있는 심볼로 취급. 성장치 부족으로 막힌 강화가 지금 고를 수 있는 어떤 강화보다 싸고 교환권으로 부족분을 채울 수 있으면 채워서 진행합니다.
  **교환권 배분은 탐욕 휴리스틱이라 최적해를 보장하지 않습니다** (뒤의 다른 지역에 아껴 쓰는 편이 더 쌀 수 있음). 결과에 교환권 사용 내역(지역별)을 표시합니다.
- 강화 효과 표시: 결과 총액 아래에 "어센틱포스 +N · 주스탯 약 +M". 어센틱포스 +10/레벨은 확정값, 주스탯 +500/레벨은 일반 직업 기준으로 알려진 값이나 **출처 확인이 안 된 값(확인 필요)** 이며 제논·데몬어벤저 등 예외 직업은 다릅니다. `data.js`의 `mainStatPerLevel`로 조정할 수 있습니다.
- 결과의 총 메소를 [메소 적립 계산기](https://yh-yeop.github.io/meso_calcul/)로 넘겨 며칠 걸리는지 바로 확인
- 성장치 부족으로 막힌 지역/레벨 안내, 부족 개수 및 일퀘 기준 소요 일수
- 결과 이미지 저장: 결과를 PNG 카드(제목·핵심 수치·지역별 현재→목표 표·사이트 주소)로 저장. 모바일은 공유 시트, 그 외는 다운로드
- 공유 링크: 상태 전체를 JSON → Base64URL 로 `#s=` 해시에 담습니다. 예전 쿼리 파라미터 링크(`?lv=…&g=…&n=…&go=b&bu=…`)도 계속 읽힙니다.
- 입력값 자동 저장(LocalStorage), 다크 모드, 업글 순서 상세
- 오프라인 캐시: Service Worker(`sw.js`)가 정적 파일을 프리캐시하고 stale-while-revalidate 로 응답합니다. 정적 파일을 수정하면 `sw.js`의 `VERSION`을 올려 주세요.
  로컬에서 옛 캐시가 거슬리면 DevTools → Application → Service Workers 에서 "Bypass for network"를 켜면 됩니다.

## 데이터
나무위키 「어센틱포스」 성장표 기준. 출처와 기준일은 `data.js`의 `meta`에 있고 화면 푸터에 "데이터 기준일"로 표시됩니다. 수치가 패치로 바뀌면 `data.js`만 수정하면 됩니다 (`meta.updatedAt`도 함께).
- 필요 성장치 (Lv.n → n+1): `9n² + 20n`
- 강화 메소: `floor(-5.4n³ + a·n² + b·n) × 100,000` (지역별 a, b). 실측 테이블을 우선 사용하고, 없으면 공식으로 계산합니다.
- 강화 1회 효과: 어센틱포스 +10 (확정), 주스탯 +500 (확인 필요)

계산 결과는 참고용이며 실제 게임 내 수치와 다를 수 있습니다.

## 구성
- `data.js` 성장표·메소 테이블·출처 메타 (패치 시 여기만 수정)
- `calc.js` 순수 계산 로직 (브라우저 `window.AUT_CALC` / Node `require`). `solve`(횟수·예산·목표 레벨·교환권), `timeline`(일퀘 타임라인), `encodeState`/`decodeState`(공유 링크 코덱)
  `create(D)`가 데이터 주입식이라, 레벨별 필요 성장치와 지역별 레벨별 메소표만 있으면 아케인심볼 같은 두 번째 체계도 같은 코드로 붙일 수 있습니다.
- `app.js` 입력·렌더링·저장·공유·Service Worker 등록
- `share.js` 결과 이미지 카드 (캔버스, `window.AUT_SHARE`)
- `sw.js` 오프라인 캐시
- `test/` Node 내장 테스트 러너용 테스트. 탐욕해가 전수조사 최적해와 같은지, 교환권·타임라인·코덱 왕복, `sw.js` 프리캐시 목록도 검사합니다.

